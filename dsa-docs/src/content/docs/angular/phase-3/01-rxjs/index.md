## Introduction
RxJS is a library for reactive programming using Observables — lazy, composable streams of values over time.

## Topics Covered

- Observables
- Subjects (Subject, BehaviorSubject, ReplaySubject, AsyncSubject)
- Operators (map, filter, switchMap, mergeMap, concatMap, exhaustMap)
- Error Handling

## Summary
RxJS is fundamental to Angular development. Master Observables and operators to handle async operations effectively."
