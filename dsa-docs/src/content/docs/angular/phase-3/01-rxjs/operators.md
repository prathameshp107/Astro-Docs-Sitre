## Introduction
Operators are functions that transform, filter, and combine Observable streams. They're composed using the pipe() method.

## Common Operators

| Operator | Purpose |
|----------|---------|
| map | Transform each emitted value |
| filter | Conditional pass-through |
| tap | Side effects (logging) |
| debounceTime | Ignore rapid emissions |
| distinctUntilChanged | Skip duplicate values |
| catchError | Error recovery |
| retry | Retry on failure |
| takeUntil | Complete on condition |

## Summary
Operators are the building blocks for reactive data transformation pipelines."
