## Introduction
Jasmine is the default testing framework for Angular. It provides a behavior-driven syntax for writing tests.

## Key Features

- describe/it blocks for organizing tests
- expect() with matchers for assertions
- beforeEach/afterEach for setup/teardown
- Spies for mocking

## Summary
Jasmine's BDD syntax makes tests readable and maintainable."
