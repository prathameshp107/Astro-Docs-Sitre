## Introduction
Route guards protect routes from unauthorized access and pre-fetch data before activation.

## Types

- **canActivate**: Can user enter?
- **canDeactivate**: Can user leave?
- **canMatch**: Should route match?
- **Resolve**: Pre-fetch data

## Summary
Combine auth and role guards to protect your application routes."
