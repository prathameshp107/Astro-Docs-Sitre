## Introduction

Services are classes that encapsulate business logic, data access, and shared functionality. Angular's dependency injection (DI) system manages how services are created and provided to components.

## Why do we need this?

Services promote code reuse and separation of concerns. DI makes services testable by allowing mock implementations to be injected during testing. Together, they form the backbone of maintainable Angular applications.

## Topics Covered

- Creating services with @Injectable
- Dependency Injection fundamentals
- Hierarchical injectors
- Provider types: useClass, useValue, useFactory
- InjectionToken for non-class dependencies

## Summary

Services + DI are essential for building scalable Angular applications. They enable code reuse, testability, and clean separation of concerns."
