## Introduction
Angular 17 introduced a new template control flow syntax using @ symbols: @if, @for, @switch.

## Topics Covered

- @if with @else
- @for with track and @empty
- @switch with @case and @default
- Migration from *ngIf, *ngFor, *ngSwitch

## Summary
The new control flow is faster, smaller, and more readable."
