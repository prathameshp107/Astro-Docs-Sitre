# History of Python

## Introduction

Python was created by **Guido van Rossum**, a Dutch programmer, during the Christmas holidays in 1989. The language was named after the British comedy group **"Monty Python's Flying Circus"** — not the snake!

### The Timeline

```
1989  →  Guido van Rossum begins work on Python during Christmas holidays
1991  →  Python 0.9.0 released (first public version)
1994  →  Python 1.0 released (lambda, map, filter, reduce added)
2000  →  Python 2.0 released (list comprehensions, garbage collection)
2008  →  Python 3.0 released (major redesign, broke backward compatibility)
2010  →  Python 2.7 released (last 2.x version)
2020  →  Python 2 officially retired (EOL - End of Life)
2023  →  Python 3.12 released (performance improvements, better error messages)
2024  →  Python 3.13 released (free-threaded mode, JIT compiler preview)
```

### The Creator

Guido van Rossum was affectionately called the **"Benevolent Dictator For Life" (BDFL)** of the Python community, meaning he had final say on all major language decisions. He stepped down from this role in 2018.

## Why It Matters

Understanding Python's history helps contextualize its design decisions and the Python 2 vs Python 3 split, which is a common interview topic.

> ⚠️ **Interview Tip**: Python 2 and Python 3 are NOT backward compatible. `print "hello"` works in Python 2 but fails in Python 3. **Always use Python 3.**

## Common Mistakes

- Using Python 2 syntax in Python 3 (e.g., `print "hello"` without parentheses)
- Not knowing the historical context of Python's design decisions

## Interview Questions

**Q1: Why was Python named "Python"?**

A: Named after the British comedy group "Monty Python's Flying Circus," not the snake. Guido wanted a short, unique, and slightly mysterious name.

**Q2: What is the difference between Python 2 and Python 3?**

A: Python 3 was a major redesign that broke backward compatibility. Key differences include `print` as a function (vs statement in Python 2), integer division returning floats (`3/2 = 1.5` vs `1`), and Unicode strings by default.
