## 💡 Study Strategy

| Step | What to do |
|------|------------|
| 1 | Solve Easy problems until you can code them without looking |
| 2 | Learn the [patterns](/DSA-Notes-Problems/data-structures/linked-list/05-patterns) — they're the building blocks for Medium problems |
| 3 | For each Medium problem, identify which patterns it uses |
| 4 | Draw the linked list on paper before coding |
| 5 | Test with empty, 1-node, and 2-node cases |
| 6 | Attempt Hard problems only after comfortably solving Medium ones |
