## Most Important Patterns to Master

| Pattern | When to Use | Key Data Structure |
|---------|------------|-------------------|
| **Frequency Counter** | Counting, duplicates, anagrams | Map / Object |
| **Two Pointer** | Sorted arrays, palindromes | Array indexes |
| **Sliding Window** | Subarrays, substrings | Queue-like window |
| **Hash Map** | Lookup, pair problems | Map / Object |
| **Set** | Uniqueness, membership | Set |
