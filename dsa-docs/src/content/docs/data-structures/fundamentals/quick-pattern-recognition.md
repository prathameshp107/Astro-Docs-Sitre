#  Quick Pattern Recognition

| Pattern             | Complexity |
| ------------------- | ---------- |
| Direct access       | O(1)       |
| Single loop         | O(n)       |
| Nested loops        | O(n²)      |
| Input halves        | O(log n)   |
| Loop + log          | O(n log n) |
| Two recursive calls | O(2)      |
