# Social Login

## Introduction

Social login lets users authenticate with their existing accounts from providers like Google, GitHub, and others. It improves sign-up conversion by removing the friction of creating a new account.

## Why This Matters

Social login is the most popular authentication method for consumer applications. Users prefer it over creating yet another username and password.

## Topics Covered

1. Google Login — Configuring Google OAuth
2. GitHub Login — Configuring GitHub OAuth
3. Custom Provider — Integrating other OAuth services

## Learning Outcomes

- Configure Google and GitHub OAuth in Auth.js
- Create OAuth apps in Google Cloud Console and GitHub
- Configure custom OAuth providers
