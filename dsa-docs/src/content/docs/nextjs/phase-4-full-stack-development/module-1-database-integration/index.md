# Module 1: Database Integration

## Introduction

Modern Next.js applications need databases. This module covers how to connect Next.js to databases using Prisma and Drizzle ORMs, handle connection pooling in serverless environments, and implement common database patterns.

## Prerequisites

- Basic knowledge of SQL
- Phase 3: Data Fetching & Server Components

## Topics

1. **Connecting to Databases** — Connection pooling, environment variables, serverless considerations
2. **Prisma with Next.js** — Schema, migrations, CRUD, relations
3. **Drizzle ORM with Next.js** — Schema, queries, relations, type safety
4. **Database Patterns** — Pagination, search, caching queries, transactions

## Learning Outcomes

- Configure database connections for serverless environments
- Model data with Prisma and Drizzle schemas
- Perform CRUD operations with type-safe queries
- Implement pagination, search, and caching patterns
