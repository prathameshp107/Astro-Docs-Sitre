# Module 4: Full Stack Architecture

## Introduction

Full-stack Next.js applications involve more than databases and APIs. This module covers file uploads, email and notifications, and background job processing — the infrastructure that powers production applications.

## Prerequisites

- Modules 1-3 of this phase
- Basic understanding of queues and async processing

## Topics

1. **File Uploads** — Direct uploads, blob storage, image optimization
2. **Email & Notifications** — Transactional email, in-app notifications
3. **Background Jobs & Queues** — Long-running tasks, scheduled jobs

## Learning Outcomes

- Handle file uploads with Server Actions and blob storage
- Send transactional emails using Resend or SendGrid
- Implement background job queues for async processing
