# Module 2: Forms & Validation

## Introduction

Production forms require validation, error handling, accessible markup, and a smooth user experience. This module covers advanced form patterns using Server Actions, Zod validation, and React Hook Form integration.

## Prerequisites

- Phase 3: Server Actions & Forms basics

## Topics

1. **Advanced Form Patterns** — Multi-step forms, dynamic fields, file uploads, optimistic UI
2. **Validation with Zod** — Schemas, error handling, type inference, custom validators
3. **React Hook Form Integration** — Client-side forms with RHF + Server Actions

## Learning Outcomes

- Build multi-step and dynamic forms
- Validate form data with Zod schemas
- Integrate React Hook Form with Server Actions
- Handle file uploads and optimistic updates
