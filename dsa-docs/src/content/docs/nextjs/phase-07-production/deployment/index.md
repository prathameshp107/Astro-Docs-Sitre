# Deployment

## Introduction

Deployment is the process of making your Next.js application available on the internet. This module covers the most common deployment targets and best practices.

## Why This Matters

How you deploy affects performance, cost, scalability, and developer experience. Choosing the right deployment strategy — and doing it correctly — is essential for production applications.

## Topics Covered

1. Introduction to Deployment — Vercel, self-hosting, and deployment models
2. Vercel Deployment — The recommended platform for Next.js
3. Self-Hosting — Docker, Node.js servers, alternative platforms
4. Environment Variables — Managing secrets across environments
5. Deployment Checklist — What to verify before going live

## Learning Outcomes

- Deploy a Next.js app to Vercel
- Understand self-hosting options (Docker, Node.js)
- Manage environment variables for different environments
- Follow a deployment checklist for production readiness
