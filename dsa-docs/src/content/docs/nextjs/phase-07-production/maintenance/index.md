# Maintenance

## Introduction

Production applications need ongoing maintenance — dependency updates, security patches, and version upgrades. Regular maintenance prevents issues and keeps your app secure.

## Why This Matters

Outdated dependencies can have security vulnerabilities. Falling too far behind on Next.js versions makes upgrades painful. Regular small updates are easier than rare large ones.

## Topics Covered

1. Updating Dependencies — Keeping packages up to date safely
2. Upgrading Next.js — Major version upgrade strategies
3. Security Updates — Applying security patches
4. Maintenance Checklist — Regular maintenance tasks

## Learning Outcomes

- Update dependencies safely with version pinning and testing
- Plan and execute Next.js version upgrades
- Apply security patches promptly
- Follow a maintenance schedule
