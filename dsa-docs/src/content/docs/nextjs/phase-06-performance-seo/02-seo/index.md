# SEO

## Introduction

Search Engine Optimization (SEO) helps your application rank higher in search results and look good when shared on social media. Next.js provides built-in tools for metadata, Open Graph, sitemaps, and robots.txt.

## Why SEO Matters

- Organic search is often the largest source of website traffic
- Proper metadata helps search engines understand your content
- Open Graph tags control how links appear on social media (Twitter, LinkedIn, Discord)
- A good sitemap helps Google discover all your pages

## Topics Covered

1. Introduction — SEO basics and how Next.js helps
2. Metadata — `generateMetadata`, static and dynamic metadata
3. Open Graph — Social media preview cards
4. robots.txt — Controlling search engine crawling
5. Sitemap — Telling search engines about your pages
6. Canonical URLs — Preventing duplicate content issues
7. SEO Best Practices — Checklist and common patterns

## Learning Outcomes

- Add metadata to pages using the Metadata API
- Generate dynamic metadata for blog posts and product pages
- Configure Open Graph tags for social sharing
- Create `robots.txt` and sitemaps
- Implement canonical URLs to prevent duplicate content
