# Project Structure

## Introduction

How you organize files and folders has a huge impact on development speed and team collaboration. A consistent structure makes it easy to find code and understand how the application works.

## Why This Matters

Without a clear structure, team members waste time searching for files, create duplicate code, and struggle to understand how parts of the application relate.

## Topics Covered

1. Folder Structure — Recommended project layout
2. Feature-Based Architecture — Organizing by features, not by file type
3. Shared Components — Building reusable component libraries
4. Reusable Hooks — Extracting stateful logic into custom hooks
5. Naming Conventions — Consistent naming for files, components, and variables

## Learning Outcomes

- Organize a Next.js project using feature-based architecture
- Build and share reusable components and hooks
- Follow consistent naming conventions
