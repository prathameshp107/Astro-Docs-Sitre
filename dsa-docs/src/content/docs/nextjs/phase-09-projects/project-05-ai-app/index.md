# AI Chat Application

## Introduction

AI-powered applications are transforming how users interact with software. This project teaches you to integrate Large Language Models (LLMs) into Next.js using the Vercel AI SDK, with real-time streaming responses.

## Project Goal

Create a ChatGPT-style chat application where users can send messages and receive AI-generated streaming responses.

## Features

- Chat interface with message history
- Streaming AI responses (typewriter effect)
- Markdown rendering with code syntax highlighting
- Multiple chat conversations
- Message persistence (database)
- Custom AI prompts and system instructions

## Prerequisites

- Server Actions and Server Components
- Client Components for real-time UI
- Streaming concepts in Next.js
- Basic API integration

## Technologies Used

- Next.js 14+ (App Router)
- Vercel AI SDK (`ai`)
- OpenAI API (or any LLM provider)
- Prisma for message storage
- Tailwind CSS

## Learning Outcomes

- Integrate AI APIs in Next.js
- Implement streaming responses with Server Actions
- Build a real-time chat interface
- Handle conversation history and context
- Structure AI application code
