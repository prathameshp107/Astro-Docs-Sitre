# Admin Dashboard

## Introduction

Admin dashboards are one of the most common real-world applications developers build. This project teaches you authentication, data visualization, protected layouts, and API integration — all essential skills for full-stack development.

## Project Goal

Create an authenticated admin dashboard with user management, data charts, and analytics overview.

## Features

- Authentication with email/password and Google OAuth
- Protected dashboard layout with sidebar navigation
- Interactive charts and data visualization
- User management table with CRUD operations
- Analytics overview with key metrics
- Responsive sidebar layout

## Prerequisites

- Authentication concepts (Phase 5)
- Server and Client Components
- Data fetching and caching
- Basic styling with Tailwind CSS

## Technologies Used

- Next.js 14+ (App Router)
- Auth.js for authentication
- Recharts for data visualization
- Prisma + SQLite for database
- Tailwind CSS

## Learning Outcomes

- Implement authentication with Auth.js
- Build protected layouts with role-based access
- Create interactive charts from database data
- Handle loading and error states in data dashboards
- Structure a multi-page dashboard application
