# E-commerce Store

## Introduction

An e-commerce store is a milestone full-stack project. It combines routing, state management, database operations, payments, and user experience patterns found in many production applications.

## Project Goal

Create a functional e-commerce store with product listings, shopping cart, checkout flow, and order management.

## Features

- Product listing with search and filters
- Product detail pages with images
- Shopping cart with add/remove/quantity
- Checkout flow with address and payment
- Order confirmation and history
- Admin order management (optional)

## Prerequisites

- App Router and dynamic routes
- Server Actions for mutations
- Client Components for interactivity
- Database basics (Prisma)

## Technologies Used

- Next.js 14+ (App Router)
- Prisma + SQLite for database
- Stripe for payments (optional)
- Tailwind CSS
- Zustand or React Context for cart state

## Learning Outcomes

- Implement a shopping cart with state management
- Build product filtering and search
- Handle payment integration with Stripe
- Manage orders and order history
- Implement checkout flow with validation
