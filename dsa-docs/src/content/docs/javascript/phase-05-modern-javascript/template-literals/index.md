# Template Literals

## Introduction

Template literals use backticks (`` ` ``) instead of quotes and support **string interpolation**, **multiline strings**, and **tagged templates**.

## Topics Covered

- [String Interpolation](./interpolation) — Embedding expressions with `${}`
- [Multiline Strings](./multiline) — Creating multi-line strings without concatenation
- [Tagged Templates](./tagged) — Custom string processing with tag functions

## Summary

Backticks for template literals, `${expression}` for interpolation, native multiline support, tagged templates for custom processing.
