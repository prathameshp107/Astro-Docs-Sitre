# Destructuring

## Introduction

Destructuring is a concise syntax for **extracting values** from arrays and objects into variables.

## Topics Covered

- [Array Destructuring](./array) — Extracting values from arrays
- [Object Destructuring](./object) — Extracting properties from objects
- [Function Parameters](./function-params) — Destructuring in function arguments

## Summary

Array destructuring: `const [a, b] = arr`. Object destructuring: `const { prop } = obj`. Default values, renaming, nesting. Excellent for function parameters.
