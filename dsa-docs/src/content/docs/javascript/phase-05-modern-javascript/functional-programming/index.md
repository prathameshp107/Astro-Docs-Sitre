# Functional Programming

## Introduction

**Functional programming (FP)** is a paradigm that treats computation as the evaluation of **pure functions** and avoids **side effects** and **mutable state**.

## Topics Covered

- [Core Principles](./core-principles) — Pure functions, immutability, and declarative style
- [Immutability](./immutability) — Avoiding mutation with spread and copy patterns

## Summary

Pure functions + immutability + declarative style. Avoid side effects and shared mutable state. Leads to testable, predictable, maintainable code.
