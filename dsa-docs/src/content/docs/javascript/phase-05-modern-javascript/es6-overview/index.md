# ES6+ Overview

## Introduction

JavaScript has evolved rapidly. ES6 (ES2015) was a landmark release, and since then, TC39 has released new features annually.

## Summary

ES6 (2015) was the biggest update — most features we use today. Annual releases since 2016. Features go through TC39 stages before inclusion.
