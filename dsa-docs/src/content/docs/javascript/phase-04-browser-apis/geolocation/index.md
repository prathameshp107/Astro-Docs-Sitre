# Geolocation API

## Introduction

The **Geolocation API** provides access to the user's geographical location through the browser.

## Topics Covered

- [One-Time Location](./one-time) — Getting the user's current position
- [Continuous Location](./continuous) — Watching position changes over time
- [Error Handling](./error-handling) — Handling permission and location errors

## Summary

`getCurrentPosition()` for one-time location, `watchPosition()` for continuous updates. Requires user permission (HTTPS). Returns latitude, longitude, accuracy.
