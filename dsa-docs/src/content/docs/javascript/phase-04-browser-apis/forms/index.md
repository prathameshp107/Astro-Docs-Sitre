# Forms

## Introduction

Forms are the primary way users submit data. JavaScript can intercept form submission, validate data, and send it asynchronously.

## Topics Covered

- [Form Events](./form-events) — Submit, input, change, and blur events
- [FormData API](./formdata) — Accessing form values programmatically
- [Validation](./validation) — Client-side form validation

## Summary

Use `e.preventDefault()` to stop form submission. `FormData` provides easy access to form values. Constraint Validation API for client-side validation.
