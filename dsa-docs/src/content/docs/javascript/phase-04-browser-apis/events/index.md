# Events

## Introduction

Events are **signals** that something has happened (click, keypress, form submit, etc.). JavaScript listens for these signals and executes code in response.

## Topics Covered

- [addEventListener](./addEventListener) — Attaching event handlers to elements
- [The Event Object](./event-object) — Properties and methods of the event object
- [Common Events](./common-events) — Mouse, keyboard, focus, form, and window events
- [preventDefault](./preventDefault) — Canceling default browser behavior

## Summary

Events signal user/browser actions. `addEventListener` attaches event handlers. The `event` object contains details. `preventDefault()` cancels default behavior.
