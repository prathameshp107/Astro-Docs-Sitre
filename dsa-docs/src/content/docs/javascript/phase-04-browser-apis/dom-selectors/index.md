# DOM Selectors

## Introduction

DOM selectors are methods that let you **find elements** in the DOM tree using CSS selector syntax or classic selection methods.

## Topics Covered

- [Modern Selectors](./modern-selectors) — querySelector and querySelectorAll
- [Classic Selectors](./classic-selectors) — getElementById, getElementsByClassName
- [Static vs Live](./static-vs-live) — querySelectorAll vs getElementsBy* collections

## Learning Objectives

- Select single and multiple DOM elements
- Understand the difference between static and live collections
- Use CSS selector syntax for powerful element selection

## Summary

`querySelector()` and `querySelectorAll()` are the modern, flexible way to select elements. `getElementById()` is fastest for IDs. Prefer modern selectors.
