# History API

## Introduction

The **History API** enables navigation through the browser session history and modifying the history stack for SPA navigation.

## Topics Covered

- [Navigation](./navigation) — Using back, forward, and go methods
- [pushState & replaceState](./pushState) — Modifying the history stack
- [PopState Event](./popstate) — Responding to back/forward navigation
- [SPA Navigation](./spa-navigation) — Building single-page app navigation

## Summary

`pushState()` adds history entries (SPA navigation). `replaceState()` modifies current entry. `popstate` event fires on back/forward. Essential for SPAs.
