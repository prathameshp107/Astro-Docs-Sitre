# Location API

## Introduction

The **Location** interface represents the current URL and provides methods for navigation and URL manipulation.

## Topics Covered

- [URL Properties](./url-properties) — Accessing parts of the URL
- [Navigation](./navigation) — Navigating to new pages

## Summary

`location` provides full URL information. Properties for protocol, host, path, query, hash. `assign()` and `replace()` for navigation. `reload()` to refresh.
