# IndexedDB

## Introduction

**IndexedDB** is a low-level, client-side NoSQL database that can store large amounts of structured data, including files/blobs.

## Topics Covered

- [Opening a Database](./opening-db) — Creating and upgrading IndexedDB databases

- [Using Promises](./using-promises) — Wrapping IndexedDB with async/await
- [Use Cases](./use-cases) — When to use IndexedDB

## Summary

IndexedDB is a client-side NoSQL database for large structured data, files, and blobs. Essential for offline/PWA applications.
