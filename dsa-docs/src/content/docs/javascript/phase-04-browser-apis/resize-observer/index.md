# Resize Observer

## Introduction

**Resize Observer** reports changes to an element's content rectangle — width and height changes — for any element, not just the window.

## Topics Covered

- [Basic Usage](./basic-usage) — Creating and using a Resize Observer
- [Use Cases](./use-cases) — Practical applications of Resize Observer

## Summary

Detects element size changes. Reports `contentRect` (width, height, left, top). Fires on any element, not just window. More efficient than polling.
