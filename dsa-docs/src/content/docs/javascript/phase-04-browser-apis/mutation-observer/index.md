# Mutation Observer

## Introduction

**Mutation Observer** watches for changes to the DOM tree — element additions/removals, attribute changes, and text modifications.

## Topics Covered

- [Basic Usage](./basic-usage) — Creating and configuring a Mutation Observer
- [Use Cases](./use-cases) — Practical applications of Mutation Observer

## Summary

Detects DOM mutations (add, remove, attribute, text). More performant than polling. Configurable to observe specific changes only.
