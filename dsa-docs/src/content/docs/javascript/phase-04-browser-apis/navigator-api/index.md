# Navigator API

## Introduction

The **Navigator** interface provides information about the browser and device capabilities.

## Topics Covered

- [Browser Information](./browser-info) — User agent, platform, language, online status
- [Device Capabilities](./device-capabilities) — Media devices, storage, connection info

## Summary

`navigator.userAgent` for browser identification, `navigator.onLine` for online/offline status, `navigator.mediaDevices` for camera/microphone access.
