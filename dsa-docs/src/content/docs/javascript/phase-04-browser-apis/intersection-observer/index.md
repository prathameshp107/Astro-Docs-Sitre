# Intersection Observer

## Introduction

**Intersection Observer** efficiently detects when an element becomes visible (intersects) with the viewport or a parent container.

## Topics Covered

- [Basic Usage](./basic-usage) — Creating and using an Intersection Observer
- [Lazy Loading](./lazy-loading) — Loading images when they become visible
- [Infinite Scroll](./infinite-scroll) — Loading more content on scroll

## Summary

Perfect for lazy-loading images, infinite scroll, animation triggers, and visibility tracking — without scroll event performance issues.
