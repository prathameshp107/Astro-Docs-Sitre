# DOM (Document Object Model)

## Introduction

The **DOM** (Document Object Model) is a programming interface for HTML documents. It represents the page as a tree of **nodes** that JavaScript can access and manipulate.

## Topics Covered

- [DOM Tree](./dom-tree) — How the DOM represents HTML as a tree structure
- [DOM vs HTML](./dom-vs-html) — The difference between the HTML source and the live DOM

## Learning Objectives

- Understand the DOM as a tree structure
- Know how JavaScript interacts with the DOM
- Differentiate between the HTML source and the live DOM

## Summary

The DOM is a tree structure representing HTML. `document` is the entry point. JavaScript manipulates the DOM to change the page. The DOM is live; the HTML file is the source.
