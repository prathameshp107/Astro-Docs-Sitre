# Objects

## Introduction

Objects are **collections of key-value pairs** and the most fundamental data structure in JavaScript. Almost everything in JavaScript is an object or can behave like one.

## Learning Objectives

- Create and manipulate objects using literals, constructors, and methods
- Understand property descriptors and configuration
- Master destructuring, spread, and Object static methods

## Topics Covered

| Topic | Description |
|-------|-------------|
| Object Literals | Creating objects with {} syntax |
| Properties | Property names, values, computed properties |
| Methods | Functions as object properties |
| Destructuring | Extracting properties into variables |
| Spread | Copying and merging objects |
| Object.freeze() | Making objects immutable |
| Object.seal() | Preventing property addition/deletion |
| Property Descriptors | Configuring property behavior |
| Object.defineProperty() | Fine-grained property control |
