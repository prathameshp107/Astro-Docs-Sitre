# Functions

## Introduction

Functions are the building blocks of JavaScript. They are **first-class citizens** — they can be assigned to variables, passed as arguments, and returned from other functions.

## Learning Objectives

- Write functions using declarations, expressions, and arrow syntax
- Understand parameters, arguments, and the `arguments` object
- Master higher-order functions, callbacks, and closures
- Use IIFEs, recursion, and pure functions

## Learning Path

```
Declarations → Expressions → Arrow Functions → Parameters → Callbacks → HOFs → Closures → Recursion → IIFE → Pure Functions
```
