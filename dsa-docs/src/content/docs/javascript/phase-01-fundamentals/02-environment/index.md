# JavaScript Environment

## 🎯 Learning Objectives

- Understand the difference between browser and Node.js environments
- Use the browser console effectively
- Master developer tools for debugging
- Write and run JavaScript in both environments

## 📖 Topics Covered

| Topic | Description | Est. Time |
|-------|-------------|-----------|
| [Browser Environment](./browser-environment) | Console, DevTools, running JS in HTML | 10 min |
| [Node.js Environment](./nodejs-environment) | Installation, REPL, running scripts | 10 min |
| [JavaScript Console](./javascript-console) | `console.log`, table, time, trace | 5 min |
| [Developer Tools](./developer-tools) | Debugger, breakpoints, network, performance | 10 min |

## 🔗 Prerequisites

- [What is JavaScript](../01-introduction/what-is-javascript)
- A modern web browser installed

## 🧭 Learning Path

```
browser-environment → nodejs-environment
         ↓
javascript-console → developer-tools
```
