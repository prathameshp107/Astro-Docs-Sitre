# Arrays

## Introduction

Arrays are **ordered collections** of values. JavaScript arrays are dynamic, zero-indexed, and can hold mixed types. They come with a powerful set of built-in methods for data manipulation.

## Learning Objectives

- Create and manipulate arrays
- Master array iteration methods (map, filter, reduce)
- Understand performance implications of array operations

## Topics Covered

| Topic | Description |
|-------|-------------|
| Creating Arrays | Literals, constructors, Array.from(), Array.of() |
| Array Methods | push, pop, shift, unshift, slice, splice |
| map | Transform each element |
| filter | Select elements by condition |
| reduce | Accumulate values |
| forEach | Iterate over elements |
| find/findIndex | Search for elements |
| some/every | Test conditions |
| flat/flatMap | Flatten nested arrays |
| sort | Sort elements |
| Performance | Time complexity and best practices |

## Estimated Learning Time

**2–3 hours**
