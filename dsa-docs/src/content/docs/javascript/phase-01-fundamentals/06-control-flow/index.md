# Control Flow

## Introduction

Control flow determines the order in which statements are executed. JavaScript provides conditionals (`if`, `switch`), loops (`for`, `while`), and jump statements (`break`, `continue`, `return`).

## Learning Objectives

- Write conditional logic with `if-else` and `switch`
- Use `for`, `while`, and `do-while` loops
- Control loop execution with `break` and `continue`

## Topics Covered

| Topic | Description |
|-------|-------------|
| if-else | Conditional branching |
| switch | Multi-way branching |
| Loops | for, while, do-while |
| break/continue | Loop control |
| Guard Clauses | Early returns for cleaner code |
