# Introduction to JavaScript

## 🎯 Learning Objectives

- Understand what JavaScript is and why it's the most popular language
- Learn the history and evolution from 1995 to today
- Distinguish JavaScript from ECMAScript
- Understand how JavaScript engines work (V8, SpiderMonkey, etc.)
- Differentiate compilation vs interpretation (JIT)
- Understand the JavaScript Runtime

## 📖 Topics Covered

| Topic | Description | Est. Time |
|-------|-------------|-----------|
| [What is JavaScript?](./what-is-javascript) | Overview, uses, and ecosystem | 10 min |
| [History of JavaScript](./history-of-javascript) | Brendan Eich, browser wars, evolution | 10 min |
| [JavaScript vs ECMAScript](./javascript-vs-ecmascript) | The specification vs the implementation | 5 min |
| [JavaScript Engines](./javascript-engines) | V8, SpiderMonkey, JavaScriptCore | 10 min |
| [Compilation vs Interpretation](./compilation-vs-interpretation) | JIT compilation explained | 10 min |
| [JavaScript Runtime](./javascript-runtime) | Browser APIs, Node.js APIs, event loop intro | 15 min |

## 🔗 Prerequisites

- Basic computer skills (file management, text editor)
- A web browser (Chrome, Firefox, or Edge)

## 🧭 Learning Path

```
what-is-javascript → history → vs-ecmascript
         ↓
engines → compilation → runtime
```
