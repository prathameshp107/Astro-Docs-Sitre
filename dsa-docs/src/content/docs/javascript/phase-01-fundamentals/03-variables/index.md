# Variables

> Variables are the **foundation** of any program — they let you store, label, and manipulate data.

## 🎯 Learning Objectives

- Declare variables using `var`, `let`, and `const`
- Understand the difference between function-scoped and block-scoped variables
- Explain hoisting and the Temporal Dead Zone (TDZ)
- Choose the right declaration for every scenario

## 📖 Topics Covered

| Topic | Description | Est. Time |
|-------|-------------|-----------|
| [var](./var) | Function-scoped, hoisting, redeclaration | 15 min |
| [let](./let) | Block-scoped, no redeclaration, TDZ | 15 min |
| [const](./const) | Immutable binding, objects & arrays | 15 min |
| [Temporal Dead Zone](./temporal-dead-zone) | What is TDZ and why it exists | 10 min |
| [Variable Hoisting](./variable-hoisting) | How hoisting works for each declaration | 10 min |
