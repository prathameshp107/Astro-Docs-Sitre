# Phase 1: JavaScript Fundamentals

> **Estimated Time:** 2–3 weeks (10–15 hours)
> **Prerequisites:** Basic computer literacy, text editor installed
> **Target:** Complete beginner → solid foundation

## 🎯 Learning Objectives

By the end of this phase, you will be able to:
- Write and execute JavaScript in browsers and Node.js
- Use variables, data types, and operators confidently
- Control program flow with conditionals and loops
- Create and use functions (declarations, expressions, arrows)
- Understand scope, closures, and hoisting
- Manipulate arrays and objects with built-in methods
- Debug code using browser developer tools
- Apply best practices and avoid common pitfalls
