# Scope

## Introduction

Scope determines the **accessibility** of variables in your code. JavaScript has global, function, and block scope, plus closures — one of its most powerful features.

## Learning Objectives

- Understand global, function, and block scope
- Master lexical scope and the scope chain
- Understand and use closures effectively

## Topics Covered

| Topic | Description |
|-------|-------------|
| Lexical Scope | Where variables are accessible based on code structure |
| Block Scope | Variables confined to blocks (let, const) |
| Global Scope | Variables accessible everywhere |
| Scope Chain | How JavaScript resolves variable access |
| Closures | Functions remembering their lexical scope |

**2–3 hours**
