# Data Types

## Introduction

Data types are the foundation of any programming language. JavaScript has a unique type system with **primitive** and **reference** types that behave very differently. Understanding data types is critical to writing bug-free code.

## Learning Objectives

- Understand the difference between primitive and reference types
- Master type conversion and coercion rules
- Know how to check types using `typeof`
- Handle special values like `NaN`, `null`, and `undefined`
- Predict type behavior in expressions

## Prerequisites

- Basic understanding of variables
- JavaScript environment setup

## Topics Covered

| Topic | Description |
|-------|-------------|
| Primitive Types | string, number, boolean, null, undefined, symbol, bigint |
| Reference Types | Objects, arrays, functions |
| Type Conversion | Explicit conversion using String(), Number(), Boolean() |
| Type Coercion | Implicit type conversion in expressions |
| Truthy & Falsy | Values that evaluate to true/false in boolean context |
| typeof Operator | Checking types at runtime |
| NaN | The special "Not a Number" value |

## Learning Path

```
Primitive Types → Reference Types → Type Conversion → Type Coercion → typeof → NaN → Truthy/Falsy
```

## Real-world Use Cases

- **Form validation**: Checking and converting user input types
- **API responses**: Parsing JSON data with correct types
- **Mathematical operations**: Avoiding NaN in calculations
- **Conditional logic**: Using truthy/falsy checks in conditions
