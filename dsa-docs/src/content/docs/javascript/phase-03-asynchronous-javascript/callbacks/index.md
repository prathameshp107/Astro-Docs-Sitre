# Callbacks & Callback Hell

## Introduction

A **callback** is a function passed as an argument to another function to be executed later. Callbacks were the original async pattern in JavaScript.

## Topics Covered

- [Callback Pattern](./callback-pattern) — How callbacks enable async operations
- [Callback Hell](./callback-hell) — The pyramid of doom and how to escape it
- [Error-First Callbacks](./error-first-callbacks) — The Node.js callback convention

## Learning Objectives

- Understand callback functions and their role in async programming
- Recognize callback hell and its problems
- Master the error-first callback pattern

## Summary

Callbacks are the foundation of all async patterns in JavaScript. While they work for simple cases, they lead to callback hell for complex sequences — which Promises solve.
