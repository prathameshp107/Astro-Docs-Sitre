# Fetch API

## Introduction

The **Fetch API** provides a modern, promise-based interface for making HTTP requests. It replaces the older `XMLHttpRequest`.

## Topics Covered

- [GET Requests](./get-requests) — Making GET requests with fetch
- [POST, PUT, DELETE](./post-put-delete) — Sending data with other HTTP methods
- [Response Methods](./response-methods) — Parsing different response types
- [Error Handling](./error-handling) — Proper fetch error handling

## Learning Objectives

- Make GET, POST, PUT, and DELETE requests with fetch
- Parse responses in different formats
- Handle HTTP errors correctly

## Summary

Fetch returns a Promise resolving to a Response object. Use `response.json()` for JSON. Check `response.ok` for HTTP errors.
