# Async/Await

## Introduction

`async`/`await` is syntactic sugar over Promises. It lets you write asynchronous code that reads like synchronous code.

## Topics Covered

- [Async Functions](./async-functions) — Declaring async functions
- [Await Keyword](./await-keyword) — Pausing execution for promises
- [Error Handling](./error-handling) — try/catch with async/await
- [Parallel Execution](./parallel-execution) — Using Promise.all with async/await
- [Top-Level Await](./top-level-await) — Using await outside async functions

## Summary

- `async` makes a function return a Promise
- `await` pauses until the Promise resolves
- Error handling uses `try/catch`
- Use `Promise.all()` for parallel operations
