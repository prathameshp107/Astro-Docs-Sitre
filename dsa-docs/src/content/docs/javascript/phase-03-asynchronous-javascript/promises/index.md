# Promises

## Introduction

A **Promise** is an object representing the eventual completion or failure of an asynchronous operation. Promises solve callback hell by providing a chainable, flat structure.

## Topics Covered

- [Promise States](./promise-states) — Pending, fulfilled, and rejected states
- [Creating Promises](./creating-promises) — Using the Promise constructor
- [Consuming Promises](./consuming-promises) — `.then()`, `.catch()`, `.finally()`

## Learning Objectives

- Understand the three states of a promise
- Create and consume promises
- Convert callback-based APIs to promises

## Summary

Promises represent async operations with three states: pending, fulfilled, rejected. They enable flat chaining and centralized error handling.
