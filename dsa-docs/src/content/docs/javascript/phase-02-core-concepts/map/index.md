# Map

## Introduction

A **Map** is a collection of key-value pairs where keys can be **any type** (objects, functions, primitives). Unlike objects, Maps preserve **insertion order** and have a `size` property.

## Learning Objectives

- Create and manipulate Map collections
- Understand Map vs Object differences
- Use Map methods: set, get, has, delete, clear
- Iterate over Maps with keys(), values(), entries()
- Know when to use Map vs Object
