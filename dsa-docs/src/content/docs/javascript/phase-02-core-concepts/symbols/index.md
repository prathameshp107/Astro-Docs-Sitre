# Symbols

## Introduction

A **Symbol** is a unique, immutable primitive value used as object property keys. Every symbol is guaranteed to be unique, even if they have the same description.

## Learning Objectives

- Create symbols with `Symbol()` and `Symbol.for()`
- Use symbols as property keys
- Understand well-known symbols
- Know when to use symbols
