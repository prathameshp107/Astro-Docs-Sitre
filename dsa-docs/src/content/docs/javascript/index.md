# JavaScript Academy

Welcome to the **JavaScript Academy** — a comprehensive, structured learning path from fundamentals to enterprise development. Built like JavaScript.info and MDN, this academy covers everything you need to master JavaScript.

## 🎯 Learning Path

<Steps>
1. **[Phase 1 — Fundamentals](/DSA-Notes-Problems/javascript/phase-01-fundamentals/)** — Start here if you're new to JavaScript: variables, data types, functions, arrays, objects
2. **[Phase 2 — Core Concepts](/DSA-Notes-Problems/javascript/phase-02-core-concepts/)** — Execution context, this, prototypes, classes, closures, memory management
3. **[Phase 3 — Async JavaScript](/DSA-Notes-Problems/javascript/phase-03-asynchronous-javascript/)** — Promises, async/await, event loop, Fetch API, Web Workers
4. **[Phase 4 — Browser APIs](/DSA-Notes-Problems/javascript/phase-04-browser-apis/)** — DOM manipulation, events, storage, IndexedDB, observers, geolocation
5. **[Phase 5 — Modern JavaScript](/DSA-Notes-Problems/javascript/phase-05-modern-javascript/)** — ES6+ features, functional programming, currying, composition, BigInt
6. **[Phase 6 — Performance](/DSA-Notes-Problems/javascript/phase-06-performance/)** — Rendering, reflow/repaint, Performance API, lazy loading, tree shaking
7. **[Phase 7 — Design Patterns](/DSA-Notes-Problems/javascript/phase-07-design-patterns/)** — Module, Singleton, Factory, Observer, Strategy, Decorator, Proxy
8. **[Phase 8 — JavaScript Internals](/DSA-notes-Problems/javascript/phase-08-javascript-internals/)** — Parser, compiler, V8, TurboFan, hidden classes, inline cache
9. **[Phase 9 — Enterprise JavaScript](/DSA-Notes-Problems/javascript/phase-09-enterprise-javascript/)** — Architecture, testing, security, clean code, error handling
</Steps>
