## Higher Order Components (HOCs)

> 🔄 This content has been consolidated into the main **[Components: Higher-Order Components](/DSA-Notes-Problems/react/components/higher-order-components)** page.

A technique for **re-using component logic** — takes a component and returns a new upgraded component. This is the legacy `data-binding` copy; the canonical version lives in the **Components** section with more detail, examples, and modern Hook alternatives.

```js
newComponent = higherOrderComponent(originalComponent);
```
