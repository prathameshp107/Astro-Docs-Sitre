## 📖 How to Use & Contribute

### Navigating the Docs

All documentation lives under `dsa-docs/src/content/docs/` organized by topic. Each section has an `index.md` overview page with a learning path and links. Pages are written in Markdown with Mermaid diagrams for visual explanations.

### Editing an Existing File

1. **Find the file**: Look in `dsa-docs/src/content/docs/[section]/filename.md`
2. **Edit it**: Make changes in your IDE — the dev server auto-reloads

### Adding a New File to an Existing Section

1. Create your `.md` file in the correct directory
2. Add frontmatter at the top:
   ```yaml
   ---
   title: "Your Title"
   description: "One-line summary"
   sidebar:
     order: <number>
   ---
   ```
3. If the section uses `autogenerate` in the sidebar config, it will be picked up automatically

### Adding a New Section

The sidebar is configured in `dsa-docs/src/config/` as modular JS files (`sidebar-*.js`):

1. **Create directory**: `dsa-docs/src/content/docs/[your-section]/`
2. **Add files** with frontmatter
3. **Create a sidebar file**: `dsa-docs/src/config/sidebar-[name].js`
4. **Import it** in `dsa-docs/src/config/sidebar.js` and add to the array

### Content Conventions

- **Frontmatter**: Every file needs `title` and `description`
- **File naming**: kebab-case (e.g., `my-new-file.md`)
- **Asset links**: Use `/DSA-Notes-Problems/assets/[path]` for images
- **Diagrams**: Mermaid code blocks (rendered as flowcharts/sequence/architecture diagrams)
- **Writing style**: Analogy → plain English → code examples → "In Simple Words" summary
